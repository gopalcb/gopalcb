## A little about me

I enjoy turning ambitious, slightly messy ideas into systems that feel clear, dependable, and easy to explore.

These days, I’m especially interested in **agent runtimes**, **human-in-the-loop workflows**, **API design**, and **observable cloud platforms**. I care about the parts behind the demo too: strong contracts, safe execution boundaries, useful logs, honest failure states, and documentation that helps the next person understand *why* the system works.

My background also includes machine learning and computer vision, so I’m happiest when a project brings together practical engineering and a little experimentation.

## How I like to work

- Make complex workflows visible and inspectable.
- Keep AI behind explicit contracts and validation boundaries.
- Build local-first when it makes development safer and faster.
- Treat testing, observability, and documentation as product features.
- Leave the codebase kinder than I found it.
